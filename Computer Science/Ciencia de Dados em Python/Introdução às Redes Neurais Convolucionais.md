Redes neurais artificiais são modelos computacionais baseados na estrutura de uma rede de neurônios biológicos. 

Com o avanço das aplicações das redes neurais, foram feitas adaptações das arquiteturas dos modelos que tinham como objetivo tratar, de forma mais especializada, determinados domínios de problemas. 

Um desses domínios de problemas é a [[visão computacional]], a qual trata das técnicas para que um sistema computacional possa distinguir objetos em cenários que podem ser estáticos ou dinâmicos e, dessa maneira, fornecer dados para que outras estruturas sistêmicas possam analisar as propriedades desses objetos ou, ainda, acionar outras ações. 

Assim surgiu as redes neurais de convolução (CNN) Convolutional Neural Network.

As CNN são uma classe de redes neurais artificiais  que é aplicada com sucesso para visão computacional. 

O projeto da CNN foi desenvolvido para que ela extraia características dos objetos de forma automática e adaptativa, por meio de algoritmo de treinamento de retropropagação, usando, para isso, vários blocos de construção como: 

- Camadas de [[convolução]];
- Camadas de pool;
- Camadas totalmente conectadas em estruturas de hierarquias espaciais.
