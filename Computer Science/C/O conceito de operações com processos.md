
## Processo

É como um programa que está sendo executado, seguindo uma ordem sequencial de instruções. Todo programa executado se transforma em processo, realizando suas tarefas. 

Quando um programa é carregado na memória para se tornar um processo, ele é segmentado em quatro partes:

1. [[Pilha]]
2.  [[Heap]]
3.  [[Dados]]
4. [[Texto]]

Um programa é um conjunto de instruções que realizam uma tarefa específica. Um processo é uma execução ativa e dinâmica desse programa. 

Durante sua execução, um pocesso transita por dirvesos estados, os quais podem diferir, dependendo do sistema operacional. Um processo pode estar em umdos cinco estados:

1. [[Iniciado]]
2.  [[Pronto]]
3.  [[Executando]]
4.  [[Esperando/Bloqueado]]
5.  [[Terminado]]

A estrutura PCB varia de acordo com o sistema operacional e é mantida durante todo o ciclo de vida do processo, sendo excluída quando ele termina. 

O sistema operacional tem uma estrutura de dados denominada [[Bloco de Controle de Processo (PCB)]]

Cada processo é identificado por um ID de processo (PID):

1. [[Estado do processo]]
2.  [[Privilégios]]
3.  [[ID do processo]]
4.  [[Ponteiro]]
5.  [[Contador de programa]]
6.  [[Registradores de CPU]]
7.  [[Informações de agendamento]]
8.  [[Gerenciamento de memória]]
9.  [[Informações contábeis]]
10.  [[Status de ES]]
