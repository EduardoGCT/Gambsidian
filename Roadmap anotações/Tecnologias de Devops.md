5. [[5 - Ansible]] (é uma ferramenta de automação de TI e infraestrutura. Na programação e desenvolvimento de software, ele é usado para automatizar tarefas repetitivas, como configurar servidores, instalar programas e implantar sistemas, utilizando o conceito de Infraestrutura como Código (IaC) para garantir ambientes consistentes.

6.  [[6 - Terraform]] (é uma ferramenta de infraestrutura como código (IaC). Ele permite que você crie, altere e gerencie recursos de TI (como servidores, redes e bancos de dados) usando arquivos de configuração baseados em texto. Isso elimina a necessidade de configurar manualmente cada máquina através de interfaces web.)
