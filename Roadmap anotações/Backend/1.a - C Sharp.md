

# What is C#?

C# (pronounced "C-Sharp") is ==a versatile, **object-oriented programming language** created by Microsoft==. It is designed to be modern, secure, and fast, functioning as the primary language for building applications on the **.NET platform**. 

Because it is cross-platform and open-source, C# is incredibly flexible and is used to build almost anything. Its most common uses include:

- **Video Game Development:** It is the standard language for making games in the widely used **Unity game engine**, as well as titles for Xbox and PC.
- **Web Applications:** Used alongside **ASP.NET**, it helps developers build dynamic websites, secure web apps, and robust **APIs** (backend server systems).
- **Enterprise Software:** Preferred by large organizations to build massive internal business systems, automated tools, and cloud services (often integrated with Microsoft Azure). 
- **Desktop & Mobile Apps:** It is used to create Windows desktop programs, and cross-platform mobile apps for iOS and Android

# How to start a project in C#?

First, use this command to create a new repo project:

`dotnet new console -n NomeDoProjeto`

Then go to your project repo in the terminal and run `dotnet run` to execute the project.

# Data Types
## Numeric Data Types.

```C#
using System;

namespace CSharp
{
	internal class Program
	{
		static void Main(string[] args)
		{
			int age = 23;

			Console.WriteLine(age);
			
			Console.WriteLine(int.MaxValue);
			
			Console.WriteLine(int.MinValue);
			
			  
			
			long bigNumber = 90000000L;
			
			Console.WriteLine(bigNumber);
			
			Console.WriteLine(long.MaxValue);
			
			Console.WriteLine(long.MinValue);
			
			  
			
			double negative = -55.2D;
			
			Console.WriteLine(negative);

			Console.WriteLine(double.MinValue);

			Console.WriteLine(precision);

			Console.WriteLine(float.MinValue);
			
			  
			
			decimal money = 14.00M;
			
			Console.WriteLine(money);

			Console.WriteLine(decimal.MinValue);
			
			  
			  
			
			Console.ReadLine();
		}
	}
}
```

## Converting strings to numbers

```C#
using System;

namespace CSharp
{
	internal class Program
	{
		static void Main(string[] args)
		{
			string textAge = "-23";

			Console.WriteLine(textAge);
			
			int age2 = Convert.ToInt32(textAge);
			
			Console.WriteLine(age2);
			
			  
			string textBigNumber = "-900000000";
			
			long bigNumber2 = Convert.ToInt64(textBigNumber);
			
			Console.WriteLine(bigNumber2);
			
			
			string textNegative = "-55.2";
			
			double negative2 = Convert.ToDouble(textNegative);
			
			Console.WriteLine(negative2);
			
			  
			string textPrecision = "5.000001";
			
			float precision2 = Convert.ToSingle(textPrecision);
			
			Console.WriteLine(precision2);
			
			  
			string textMoney = "14.99";
			
			decimal money2 = Convert.ToDecimal(textMoney);
			
			Console.WriteLine(money2);
			
			  
			
			Console.ReadLine();
		}
	}
}
```

# Operators

## + - * /

```C#
using System;

namespace CSharp
{
	internal class DataTypes
	{
		static void Main(string[] args)
		{
			int age3 = 23;

			Console.WriteLine(age3);
			
			age3++;
			
			Console.WriteLine(age3);
			
			age3 = age3 - 4;
			
			Console.WriteLine(age3);
			
			age3 += 10;
			
			Console.WriteLine(age3);
			
			
			// + - * /
			
			age3 *= 10; // age3 = age3 * 10;
			
			Console.WriteLine(age3);
			
			  
			age3 /= 10; // age3 = age3 / 10;
			
			//in / you have to use a var double, or if the result its gonna cut the float numbers.
			
			Console.WriteLine(age3);
			
			  
			// How Opertors react to strings
			
			  
			string name2= "Aba";
			
			name2 += " is programming!"; // name2 = name2 + " is programming"
			
			Console.WriteLine(name2);
			
			// you can't use - in string
			
			  
			//when you use operators in char, the C# is gonna use the 2 chars encodes to combine and serch to the char made with it
			
			char ch = 'a';
			
			ch += 'b';
			
			Console.WriteLine(ch);
			
				
			//if you use ++ in 'Console.WriteLine()' you have to put the ++ first
			int i = 0;
			
			Console.WriteLine(++i);
			
			//if you increment after, the var it's gonna be printend before the incrementation
			
			  			
			Console.ReadLine();
		}
	}
}
```
